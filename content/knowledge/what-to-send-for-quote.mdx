อยากได้ใบเสนอราคาที่ “ตรงรุ่น ราคาเร็ว ไม่ต้องถามกลับหลายรอบ” เคล็ดลับคือส่งข้อมูลให้ครบตั้งแต่แรก
บทความนี้เป็นเช็คลิสต์สั้น ๆ ที่ช่วยให้ทีมวิศวกรเลือกรุ่นได้ตรงและเสนอราคาได้ไว

## เช็คลิสต์ข้อมูลที่ควรส่ง

| ข้อมูล | ทำไมสำคัญ |
| --- | --- |
| รูป Nameplate มอเตอร์ (หรือ kW/HP + แรงดัน) | ใช้หาช่วงกระแสที่เหมาะ |
| กระแสพิกัด / กระแสที่ตั้งไว้ | จับคู่ช่วงรุ่นให้พอดี |
| ฟังก์ชันป้องกันที่ต้องการ | เลือกซีรีส์ให้ตรง (โหลดเกิน/ขาดเฟส/ไฟรั่ว/โหลดต่ำ) |
| แรงดันไฟควบคุม | เลือกรุ่นให้ตรงระบบควบคุม |
| เอาต์พุต / รูปแบบติดตั้ง | ให้เข้ากับวงจรและพื้นที่ในตู้ |
| จำนวนที่ต้องการ | คิดราคาและเช็คสต๊อก |
| รุ่นเดิม (ถ้าเปลี่ยนทดแทน) + รูปการต่อสาย | หาตัวแทนที่ใช้แทนกันได้ |

<Callout type="info" title="ไม่มี Nameplate ชัดก็เริ่มได้">
ส่ง kW/HP กับแรงดันมาก่อน ทีมช่วยประมาณกระแสด้วย [เครื่องคำนวณกระแสมอเตอร์](/learn/motor-current-calculator/)
แล้วยืนยันช่วงกระแสด้วย [เครื่องช่วยเลือกช่วงกระแส EOCR](/learn/eocr-current-range-calculator/) อีกครั้ง
</Callout>

## ส่งข้อมูลมาทาง LINE ได้เลย

วิธีที่สะดวกที่สุดคือแนบรูป Nameplate/ตู้ และพิมพ์จำนวนที่ต้องการส่งมาทาง **LINE ของ SAV** ทีมจะเลือกรุ่น
และเสนอราคากลับให้ ถ้าเป็นการเปลี่ยนทดแทน อย่าลืมแนบรุ่นเดิมและรูปการต่อสายด้วย
