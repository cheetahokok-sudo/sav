การสั่งรีเลย์ป้องกันมอเตอร์ให้ “ได้รุ่นที่ใช่ในครั้งเดียว” ช่วยลดการส่งคืน/เปลี่ยนรุ่นและเวลาที่เครื่องหยุด
หน้านี้เป็นคู่มือหลักสำหรับฝ่ายจัดซื้อและช่างซ่อมบำรุง เชื่อมไปยังบทความย่อยแต่ละเรื่อง

## ข้อมูล 5 อย่างที่ต้องมี

| ข้อมูล | ดูจาก |
| --- | --- |
| ช่วงกระแส (setting range) | กระแสพิกัดมอเตอร์ หรือ kW/HP + แรงดัน |
| ฟังก์ชันป้องกัน | ความเสี่ยงของงาน (โหลดเกิน ขาดเฟส โหลดต่ำ ไฟรั่ว ฯลฯ) |
| แรงดันไฟควบคุม | ระบบควบคุมในตู้ (24VDC / 110 / 220VAC) |
| เอาต์พุต / การรีเซ็ต | วงจรควบคุมที่ออกแบบไว้ (คอนแทค, Auto/Manual) |
| รูปแบบติดตั้ง | พื้นที่ในตู้ (DIN Rail / Panel) |
