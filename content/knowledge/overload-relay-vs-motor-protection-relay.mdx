หลายคนใช้คำว่า “Overload Relay” และ “Motor Protection Relay” ปนกัน แต่ในทางปฏิบัติมีความต่างที่สำคัญ
บทความนี้เปรียบเทียบให้ชัดเพื่อเลือกใช้และทดแทนได้ถูก

## หลักการทำงานที่ต่างกัน

**Thermal Overload Relay** (แบบไบเมทัล) อาศัย **ความร้อน** จากกระแสที่ไหลผ่าน ไปงอแผ่นโลหะสองชนิด (bimetal)
เมื่อร้อนถึงจุดหนึ่งจะตัดวงจร ข้อดีคือเรียบง่าย ราคาถูก แต่ตอบสนองช้า ตั้งค่าหยาบ และได้รับผลจากอุณหภูมิห้อง

**Motor Protection Relay อิเล็กทรอนิกส์ (EOCR)** วัดกระแสจริงแบบทันที แล้วประมวลผลด้วยวงจรอิเล็กทรอนิกส์
จึงตั้งค่าละเอียด แม่นยำกว่า และเพิ่มฟังก์ชันป้องกันได้หลายอย่าง

## เปรียบเทียบแบบตาราง

| หัวข้อ | Thermal Overload | Motor Protection Relay (EOCR) |
| --- | --- | --- |
| หลักการ | ความร้อน (ไบเมทัล) | วัดกระแสจริงแบบอิเล็กทรอนิกส์ |
| โหลดเกิน | ✓ | ✓ |
| ขาดเฟส | จำกัด | ✓ |
| กระแสไม่สมดุล | ✕ | ✓ (บางรุ่น) |
| โหลดต่ำ / เดินแห้ง | ✕ | ✓ (บางรุ่น) |
| Ground Fault | ✕ | ✓ (บางรุ่น + ZCT) |
| แสดงค่ากระแส/สาเหตุ Trip | ✕ | ✓ (รุ่น Digital) |
| ผลจากอุณหภูมิห้อง | มี | น้อยกว่า |

<Callout type="info" title="สรุป">
ต้องการแค่กันโหลดเกินราคาประหยัด → Thermal Overload ยังใช้ได้ · ต้องการหลายฟังก์ชัน ความแม่นยำ และข้อมูลเพื่อบำรุงรักษา → EOCR ดิจิทัลคุ้มกว่า
</Callout>

## เลือกอย่างไร / ทดแทนอย่างไร

ถ้าต้องการอัปเกรดจาก Thermal Overload เดิม ให้เทียบ **ช่วงกระแส** และ **แรงดันควบคุม** ให้ตรง
ตรวจรูปแบบเอาต์พุตและพื้นที่ในตู้ แล้วดูขั้นตอนละเอียดใน [วิธีเลือก EOCR ให้เหมาะกับมอเตอร์](/knowledge/how-to-select-eocr/)

## มาตรฐานที่เกี่ยวข้อง

ทั้งสองประเภทเป็นส่วนหนึ่งของ Motor Starter ตาม **IEC 60947-4-1:2023 (Ed. 5.0)** โปรดตรวจ Datasheet
ของรุ่นและฉบับมาตรฐานล่าสุดก่อนตัดสินใจ
